# Осенний конкурс операторов — сентябрь 2026

Новая версия сайта собрана по визуальному референсу: тёплая осенняя сцена, стеклянные панели, каминная атмосфера, грибы, лукошки и ёжики.

## Данные
- `data/contest.json` — участники и количество успешек.
- Видимый рейтинг — только топ-7.
- Победители — места 1–3.
- 4–7 места остаются в итоговом топе без денежного приза.

## Запуск
Откройте `index.html` через локальный статический сервер, если браузер блокирует `fetch()` для JSON при открытии файла напрямую.
